Sobre o CharacterVerse

Conheça a ideia por trás da nossa pequena Wiki de personagens.

O projeto

Uma Wiki criada para reunir histórias favoritas

O CharacterVerse é um projeto desenvolvido com a ideia de criar uma pequena enciclopédia de personagens. O objetivo é reunir informações sobre personagens importantes para cada participante, apresentando suas histórias, poderes e características.

A inspiração veio de grandes páginas Wiki, que organizam informações de personagens de forma simples, bonita e fácil de consultar.

Tecnologias utilizadas

  • HTML5
  • CSS3
  • JavaScript
  • Bootstrap
  • JSON com Fetch API
Funcionamento

Como o site funciona?

1. Dados

As informações dos personagens ficam armazenadas no arquivo personagens.json, que funciona como uma pequena API local.

2. Fetch API

O JavaScript utiliza o fetch() para buscar os dados do JSON e preencher automaticamente as páginas.

3. Página dinâmica

Cada personagem possui uma Wiki própria usando o mesmo modelo de página.

Organização dos arquivos

  • HTML → Estrutura das páginas
  • CSS → Estilização e responsividade
  • JavaScript → Interações e carregamento dos dados
  • JSON → Banco de dados dos personagens
  • Imagens → Personagens e backgrounds
